# mango-config
my mango config

# Usage
```bash
git clone https://github.com/BURRR-e/mangowc_config ~/.config/mango
```
## Some Common Default Keybindings

- super+return: open foot terminal
- ctrl+shift+space: open rofi launcher
- super+q: kill client
- super+left/right/up/down: focus direction
- super+m: quit mango
